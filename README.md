# ✈️ Site de Viagens

## 📌 Sobre o Projeto

Este projeto consiste em um site sobre viagens, desenvolvido com o objetivo de apresentar destinos turísticos e informações relacionadas ao turismo. O projeto também permite praticar os conhecimentos adquiridos durante os estudos de Desenvolvimento de Sistemas, utilizando tecnologias de desenvolvimento web.

## 🚀 Tecnologias Utilizadas

- **HTML5:** estruturação das páginas do site.
- **CSS3:** estilização e organização visual.
- **Git e GitHub:** versionamento e armazenamento do projeto.

## ✨ Objetivos

- Desenvolver conhecimentos em HTML e CSS.
- Praticar a criação e organização de páginas web.
- Criar uma interface visual relacionada ao tema de viagens.
- Aplicar os conhecimentos adquiridos durante as aulas.

## 📂 Estrutura do Projeto

```text
viagem/
├── index.html    # Página principal do site
├── css/          # Arquivos de estilização
├── img/          # Imagens utilizadas no projeto
└── README.md     # Documentação do projeto
```

## ▶️ Como Executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/LucasMiguel822/viagem.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd viagem
   ```

3. Abra o arquivo `index.html` em um navegador para visualizar o site.
